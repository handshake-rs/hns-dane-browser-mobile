# Shakescape Brand Guide

## Public identity

**Shakescape** is the public product name on Android, iOS, browser-extension
surfaces, current store listings, and customer-facing documentation.

Use **Shakescape Wallet** for the website-provider display label and
**Shakescape Setup** for the desktop setup application's visible name.

Application IDs, bundle IDs, source packages, storage paths, native-host IDs,
and certificate identities are stable contracts and require explicit coordinated
changes independently of visible product naming.

## Visual system

- Primary background: `#0A0E17`
- Primary accent: `#00FFE0`
- Supporting violet: `#785CFF`
- Supporting magenta: `#FF2E9E`
- Supporting yellow: `#FFD35C`
- Primary light text: `#E6F3FF`
- Brand headings: Orbitron with expanded letter spacing
- Interface and body copy: Inter or the platform system sans-serif

The canonical mark is the full-color folded-ribbon **S**. Use the mark alone
for compact icons and the horizontal Shakescape lockup where space permits.
Dark navy surfaces, restrained cyan/violet glow, fine grid or topographic line
work, and high-contrast text form the shared visual language.

Tagline: **Explore the web.**

## Product language

The Shakescape name does not replace protocol terminology. Continue to use
technical phrases such as:

- `Handshake-first`
- `HNS proofs`
- `DNSSEC/DANE`
- `TLSA validation`
- `RFC 8484 DoH transport`
- `authoritative DoH for delegated HNS names`

Do not promise a `CA-free browser`, `trustless HTTPS`, or generalized ICANN
DANE behavior. Ordinary ICANN browsing can still use WebPKI, and the interface
must continue to report the exact trust and resolution path.
