Shakescape is a dual-root browser that resolves both ICANN and Handshake names and shows how each selected path was authenticated.

Browser features:

- Browse Handshake names such as example/ and name.tld/
- Sync and verify Handshake headers and name proofs on your device
- Resolve delegated names through authoritative DNS or proof-anchored authoritative DNS-over-HTTPS
- Validate DNSSEC, TLSA, and DANE policies locally
- Inspect resolver paths, proof details, and security status
- Optionally enable requester-only HNS peer-to-peer DNS relay consumption
- Optionally configure recursive HNS DoH recovery when direct authoritative resolution is blocked
- Keep HNS answers subject to local proof, DNSSEC, TLSA, and DANE validation without an HNS WebPKI fallback
- Keep website data in a persistent WebKit profile
- Download files and share pages with standard iOS controls

Native HNS wallet features:

- Create or restore one device-local Shakescape wallet
- Unlock it with device-protected key storage
- Synchronize balance and recent activity directly with Handshake peers
- Receive HNS with an address or payment QR code
- Review and approve guarded HNS sends with an explicit fee cap
- Import tracked Handshake names and set a restoration birthday height
- Delete the encrypted local wallet through a protected confirmation flow

Wallet actions remain inside the native app. Websites cannot invoke wallet operations or receive wallet data, and the app does not install a website wallet provider. Recovery phrases and private keys are not sent to Denuo Web or analytics services. The camera is used only when you choose to scan a Handshake payment QR code; the decoded address is processed on the device.

The native wallet also exposes tracked-name management, supported name transfer/finalization and raw-record actions, and capability-gated direct Shakedex and Bitcoin controls. These controls remain inside the app, require an unlocked synchronized wallet and explicit native approval where value can move, and may remain unavailable until their native prerequisites are satisfied. The app has no developer-operated account, advertising SDK, analytics SDK, subscription, in-app purchase, custodial exchange service, or paid feature unlock.
