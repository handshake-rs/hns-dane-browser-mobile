No sign-in is required. The app has no developer-operated account, subscription, in-app purchase, or payment flow. Its native wallet screen manages one device-local HNS account identity and displays strict read-only fields for balance, distinct payment and name-transfer receive targets, transaction history, tracked names, and module status plus exact-text name import. This build installs no scoped companion credential or indexed backend, so those fields and name import remain unavailable. Sending or value movement, website-provider access, HNSA/HNSR, settlement, exchange features, and P2P marketplaces are unavailable.

Shakescape uses WKWebView for rendering and an authenticated loopback proxy at 127.0.0.1 for app traffic. It does not install a VPN or change the device's system proxy.

Ordinary web test:
1. Launch the app. When "Enter an address to begin" appears, enter https://denuoweb.com/work/hns-dane-browser and tap Go.
2. Confirm the page loads and the security label shows the WebPKI path.

Handshake test:
1. Enter https://denuoweb/ and tap Go.
2. The bundled Handshake header snapshot allows immediate proof-backed resolution while foreground header sync continues.
3. Confirm the security label identifies the resolver and TLS validation path.
4. Tap the Settings gear button to inspect HNS resolution, HNS sync, Clear resolver cache, Resolver trace, HNS proof details, Privacy policy, and Source code.

Native wallet control test:
1. Tap the Settings gear button, then Handshake wallet.
2. A fresh install reports that no native wallet exists. Create and restore are local operations; a reviewer does not need to create a wallet to evaluate browsing.
3. If Create is exercised, record the one-time recovery phrase only in a secure reviewer-controlled location and confirm it. The screen then supports open, unlock, lock, and inspection of one account identity. Face ID or the device passcode may be requested to retrieve the device-bound database key.
4. An unlocked confirmed wallet exposes Delete confirmed wallet. It shows the exact network/account twice and requires typing DELETE. This removes the device-bound key before encrypted local database files; it does not remove a recovery phrase saved elsewhere.
5. Confirm the read-only balance, payment-receive, name-transfer-receive, history, tracked-name, and module rows report that the scoped companion credential is not installed. Synchronization cannot start in this candidate.
6. Confirm exact-text name import is disabled with the missing-backend message. No send/value, website-provider, HNSA/HNSR, settlement, exchange, or marketplace action is available.

Network note: some review networks block Handshake peer traffic or direct authoritative DNS. Experimental P2P DNS relay consumption is off by default and requires explicit requester opt-in in Settings. A separate recursive HNS DoH recovery URL is also blank by default; the app contacts no such operator unless the user explicitly enters a validated HTTPS endpoint. Its operator can observe queried names/types, timing, and source IP. Relay and configured-recursive answers still require local proof, DNSSEC, TLSA, and DANE validation, and the app never substitutes WebPKI for required HNS DANE. If no permitted validated path succeeds, the HNS request fails closed.

Cleartext HTTP pages are marked insecure. No reviewer-supplied personal data or credentials are needed. The two test URLs above are developer-controlled.
